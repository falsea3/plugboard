README

Most developer tools now open with a sign-up screen, sync your work to someone else’s cloud and report what you click. Relay and Plugboard go the other way: plain desktop apps that keep your work in files you own and reach the network only for what you point them at.

Principles

01

Local-first

Connections and settings are plain files in your user folder. Passwords go to the system keychain, never into a config file.

02

No telemetry

No analytics, no crash reporter, no usage pings. The update check is the only request the apps make without asking.

03

No account

Download, open, work. There is nothing to sign up for and no login screen.

04

Open source

MIT Licensed. Read the code, build it yourself, send a fix.
