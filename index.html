Why Plugboard

Free, all of it

No account, no trial that runs out, no Pro tier holding back features. MIT licensed.

Six engines, one app

PostgreSQL, MySQL and MariaDB, SQLite, ClickHouse, Cassandra, Redis and Valkey — several open at once.

Passwords stay yours

Kept in the system keychain, never in a file and never synced anywhere. No analytics, no crash reporter.

Two locks on production

Read-only is enforced by the app and by the database session itself, so a write that slips past one still meets the other.

Moving from another client?

Bring your connections along instead of typing them in again.

All features in the README

From DBeaver

  1. On the home screen, choose Import from DBeaver.
  2. Plugboard finds DBeaver’s connections and shows which are already here.
  3. Pick the rest and import them.

What comes along

  • Folders → groups
  • SSH tunnels
  • Saved passwords
  • Hosts, ports, databases

From URL

  1. Copy a connection URL, a JDBC URL or a line from a .env file.
  2. Paste it into the new connection form — the fields fill themselves in.
postgres://app:secret@db.example.com:5432/shop?sslmode=require

What comes along

  • Driver
  • Host and port
  • User and password
  • Database
  • SSL mode

Hard to break production by accident

Plugboard assumes the database you are connected to might matter.

  1. Read-only connections, on by default for anything tagged Production — refused in the app and in the database session itself.

  2. Writes to Production ask first and show exactly what will run.

  3. Grid edits are applied in one transaction: every change lands, or none does.

  4. A write is never re-run behind your back after a dropped connection.

  5. A changed SSH host key is refused until you have seen and trusted the new fingerprint.

Check what you download

Every release ships SHA-256 checksums and signatures, and the in-app updater refuses a build that fails either check. To check an installer yourself, put it next to SHA256SUMS.txt from the same release and run:

The builds aren’t signed by Apple or Microsoft yet, so the first launch shows a warning. Here is what to click.

Older versions and their checksums are on GitHub.

macOS shasum -a 256 -c SHA256SUMS.txt --ignore-missing
Linux sha256sum -c SHA256SUMS.txt --ignore-missing
Windows Get-FileHash .\installer.exe -Algorithm SHA256

What leaves your machine

The complete list. There is no analytics endpoint, so there is nothing to opt out of.

  • The databases you connect

    Directly or through your SSH tunnel. AI agents reach them only through Plugboard on your machine.

  • Your SSH servers

    A changed host key is refused until you have seen and trusted it.

  • GitHub, for updates

    To look for a new version. Install it yourself or let it update on its own.

Where your data lives

On your disk, in formats you can open without the app.

  • Passwords in the system keychain

    Keychain, Windows Credential Manager or Secret Service — never a file on disk.

  • Connections in a plain JSON file

    In your profile folder, where you can read it, back it up or delete it. Scripts are plain .sql files.

FAQ

Short answers to what people ask most.

Ask on GitHub
01 Which databases does Plugboard support?

PostgreSQL, MySQL and MariaDB, SQLite files, ClickHouse, Cassandra, and Redis or Valkey — several connections open at once, each with its own tabs.

02 Is it really free?

Yes. It is open source under the MIT license, with no account, no trial and no paid tier.

03 Is Plugboard a TablePlus or DBeaver alternative?

It covers the same daily work — browsing and editing tables, a SQL editor, structure, SSH tunnels — as a small native-feeling app, free on macOS, Windows and Linux. Connections from DBeaver import in one go.

04 Can it open pg_dump files?

Yes. It imports plain SQL dumps (also .gz) and pg_dump’s custom (-Fc) and tar archives, and exports in the same formats, which pg_restore reads.

05 How do AI agents use it?

Plugboard is also an MCP server. Add it to Claude Code, Codex or Cursor with the command from Settings ▸ AI agents. Agents see only connections you allow, read-only unless you say otherwise, and never get a password.

06 macOS says the app can’t be opened. What now?

The builds aren’t signed by Apple yet. Open it once, then click Open Anyway in System Settings ▸ Privacy & Security. You only do this once.

07 Windows shows “Windows protected your PC”.

The builds aren’t signed by Microsoft yet. Click More info ▸ Run anyway. Updates the app installs itself don’t ask again.
